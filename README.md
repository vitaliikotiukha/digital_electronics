# Цифрова схемотехніка (Digital Electronics)

Навчальний репозиторій з лабораторними роботами та матеріалами курсу цифрової схемотехніки на платформі Arduino.

## Структура репозиторію

* **Lab-1/** — Лабораторна робота №1: базова робота з цифровими пінами та світлодіодами.
* **Lab-2/** — Лабораторна робота №2: система моніторингу пожежної безпеки (NTC-терморезистор + датчик полум'я + RGB-світлодіод).
* **Lab-3/** — Лабораторна робота №3: дослідження RS-тригера на базі елементів АБО-НЕ (NOR) та моніторинг станів.
